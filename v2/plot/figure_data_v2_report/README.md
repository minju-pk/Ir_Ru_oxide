그림 폴더의 PNG 17장에 찍힌 **모든 점의 값**을 표 두 개로 정리한 것입니다.
그림을 다시 계산한 것이 아니라, 그림을 만든 것과 같은 집계에서 나온 값입니다.

| 파일 | 대상 그림 | 한 행 = | 행 수 |
|---|---|---|---|
| `figure_data_scalar.csv` | x축이 O 조건인 그림 13장 — Fig 1b · Fig 2a(m=1, 2) · Fig 3 / S3 (size · perc) | 그림의 점 하나 (케이스 × region × 양) | 2,400 |
| `figure_data_depth.csv` | x축이 층 번호인 그림 4장 — Fig 1a · Fig 2b(m=1, 2) · Fig 2c | 선 위의 점 하나 (케이스 × 층 또는 층 쌍) | 1,593 |

`figure` 열이 PNG 파일 이름(확장자 제외)이라, 그 열로 필터하면 그림 한 장의 데이터만 남습니다.

## 데이터와 집계

- 데이터: Monte Carlo 30 케이스 (x_Ir 0.25 / 0.50 / 0.75 × (100) / (110) / (111) × O 조건, (111) stoich은 S1·S2 두 개)
- 집계 구간: MC 601–1100 스텝
- 평균: **MC 스텝 점유 구간 가중 평균** (한 구조가 머문 스텝 수를 가중치로 사용)
- `sd`: 같은 가중의 표준편차 = **스텝 간 요동의 크기**입니다. 평균의 오차(standard error)가 아닙니다. 그림의 오차막대·띠가 이 값입니다
- region: TS / BS = 위·아래 표면 1층, TSS / BSS = 그 안쪽 1층, bulk = 나머지. 층 라벨은 초기 구조에서 정해 전 구간에 고정

## 해석할 때 꼭 볼 두 열

**`valid_fraction` — 값이 몇 % 시간 동안 정의됐는가**
층이 한 원소로만 채워지면 α는 기댓값 f_0 = 0이 되어 정의되지 않고, D·H는 region에 그 원소가 없으면 정의되지 않습니다(NA).
`mean`은 **정의된 스텝만의 평균**입니다. `valid_fraction`이 0이면 `mean`이 비어 있고 그림에도 점이 없습니다.

**`single_atom_share` — 값이 배열과 무관하게 정해진 비율**
소수 원소가 1개뿐이면 실제 배열과 상관없이 값이 하나로 정해집니다.

| 양 | 조건 | 고정값 |
|---|---|---|
| `alpha_in` (TS / BS / TSS / BSS) | 그 층의 소수 원소가 1개 | α = 0 |
| `D_a` · `H_a` | region 안 원소 a가 1개 | D = 1, H = 0 |
| `alpha_out` | 두 층 중 하나가 한 원소뿐 | α = 0 |

데이터 전체에서 위 조건에 해당하는 프레임이 예외 없이 고정값이었습니다(오차 < 1e-12).
이 비율이 높은 점의 α = 0, D = 1, H = 0은 "무작위 혼합"이나 "한 덩어리"를 뜻하지 않습니다.
해당하지 않는 양은 빈칸입니다(`alpha_in` bulk는 여러 층의 합이라 이 규칙이 적용되지 않습니다).

> 예: (100) x_Ir = 0.25 O-rich, TS의 `D_Ir` = 1.0 → `valid_fraction` 0.07, `single_atom_share` 1.00.
> 표면에 Ir이 1개 있던 7%의 시간 동안의 값입니다.

이런 점은 대부분 (111)에 있습니다(층당 16 site). (110)에는 없습니다.

## 정의에 관한 메모

- α_in / α_out: 층 조성을 기준(f_0)으로 한 Warren–Cowley 형태. α > 0 동종, α < 0 Ir–Ru 교대
- 껍질 탐색의 면내 상한은 6.6 Å입니다(스펙 6.0 Å). (111) 면내 두 번째 껍질(6.41 Å, `alpha_in` m = 2)을 포함하기 위해서입니다
- Fig 2c ((111), Δlayer = 2)는 스펙의 "인접 층"(Δlayer = 1) 밖입니다. (111)의 최근접 cation 결합(3.15 Å)이 두 층 건너에 있어 별도로 냈습니다
- Domain graph: 층별 면내 대칭화 k = 4 그래프, 초기 구조에서 고정. (110)은 4번째 이웃이 4개 동률이라 동률을 모두 포함했습니다(이웃 6개)
- percolation 방향 a / b는 격자벡터 방향입니다((111)은 데카르트 x / y가 아님). `P`는 관통한 스텝의 비율
- `I_R`은 조성 보정이 없습니다. 완전 무작위여도 약 2x(1−x)가 나옵니다
- D · H · I · P에는 무작위 baseline이 없습니다
